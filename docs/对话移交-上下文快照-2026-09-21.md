## 0. 一句话定位 + 是不是 Agent

**VeriFin = A 股年报财报数字「可溯源核验」Agent**：用户（或系统）拿着一份年报、问一个数字，系统把它**逐字定位回原文页码 + 那一行坐标**，并做内部勾稽一致性检查；拿不准就程序级拒答，绝不编。

**是不是 Agent（用户反复质疑的点，结论要讲清）**：
- 四要素 LLM + 工具 + 记忆 + 控制流**都齐**，所以**是 Agent**；
- 但它是**"受限编排 Agent"**：主核验链路是**确定性工作流**（不经 LLM），Agent 只是叠在最前面的**受控路由层**；
- LLM 的**唯一权力**是在图的"合法后继"里挑一个**节点名**——不能填工具参数、不能改数值、不能决定拒答；六元组缺字段时程序级拒答，模型无否决权。
- 讲给面试官的口径："我们不是让 LLM 去算账，而是让 LLM 在受约束的图里选下一步；取值、算术、拒答判定全部走确定性代码。"

## 3. 已完成功能（按层）

### 核验主链路（确定性，不经 LLM）
四路召回 → RRF(k=60) 融合 → span 硬校验（两层关卡） → PyMuPDF 同行坐标定位 → 六元组（公司/期间/指标/数值/单位/来源）组装 / 程序级拒答。

### 解析
- MinerU 4.x 出表格与页码；doclib 无 bbox → PyMuPDF 出绝对坐标（必需组件非可选）。
- 跨页表格拼接（`stitch_file`）：续页重复表头、按科目名合并，保留每行来源页码。
- 降级链：MinerU → Docling → pdfplumber → PyMuPDF。

### 检索（四路 + RRF）
`label`（精确科目名）/ `lexical`（FTS5 + jieba，查询侧必切词）/ `numeric`（Decimal 精确，纯数字不进词法）/ `vector`（端点无 embedding → 本地 TF-IDF 兜底）。融合 RRF k=60。

### Agent 编排（D3）
- 显式图 **12 节点 / 8 工具**，声明式字典 `GRAPH`；节点：INTENT/GUARD/SEARCH/EVIDENCE/VERIFY_SPAN/LOCATE/LIST_FORMULAS/COMPUTE/DIFF/ANSWER/REFUSE/ABORT。
- **LLM 只选节点名**，工具入参由图从 state 填（红线：绝不让 LLM 产出工具入参 / 数值）。
- 预算三件套 `max_steps=12 / max_tool_calls=10 / max_llm_calls=8`，**按次运行计**（`run()` 开头 `planner.reset()`）。
- 降级一律标 `source="policy"`（LLM 未配/调用失败/返回非法值/预算用尽），非法选择额外记 `raw_choice`，**降级不掩盖**。
- `tests/test_agent.py` **零真实 LLM、零真实 PDF**——调度器/资源/句柄全可注入，红线"LLM 不参与数值"只有在无 LLM 环境才能被证明。

### 口径与护栏（D5）
- 口径只在主表标题上（`## 合并资产负债表` → 合并；推不出返回 `None` 不许当合并）；识别集中 `verifin/scope.py`。
- 口径歧义必须在 `rt.resolve(label, None)` 之前判（两套都有且问句未限定 → `AMBIGUOUS_SCOPE`）。
- 取数四处共用一套消歧 `_resolve_scoped`（取行/坐标/span/勾稽）。
- 约束从文档自身推导（`DocConstraints`：发行人=编制单位、年份=表头），不硬编码。
- 主体/期间约束**判断不了就放行**（误拦会把正确回答变拒答）；**问答一致性判断不了就拒答**（错一个财务数字不是体验差）。
- 「两行相减」是独立动作（DIFF 节点 + `diff_two_rows`），不属 LOOKUP 也不套公式。

### 评测（D4/D5 + D6）
- gold 三道独立闸门：**G1** 索引页 / **G2** 证据片段同页可定位 / **G3** 原始 PDF 文本层（唯一独立于本项目解析产物的闸门，过不了就排除"解析错、标注跟着错"的自洽型错误）。
- 派生量题（毛利率）答案在 PDF 里不存在 → 带 `gold_operands`，G1/G3 校验操作数而非答案。
- 判定型题必须带 `gold_operands`（同一恒等式在合并/母公司两套口径下都平衡，只看 PASS 会把"取到真数、答错报表"判成对）。
- `ABORT` ≠ `REFUSE`（前者没算完，后者证据不足，混同会把规划器缺陷记成召回失败）。
- 口径四值：合并 / 母公司 / 跨口径 / 不适用（跨口径单列不并进不适用）。
- R 题 `refusal_reason` 机器可读前缀：`no_recall` / `out_of_document_period` / `wrong_document` / `out_of_parse_window` / `ambiguous_scope`。
- D6：网络重试（`RetryPolicy`/`RateLimiter`）与格式降级分离；输入校验 `validate_question`（200 字）；成本指标（每问 token 差）；Track D 对抗 7 题（数值伪造 5 + 越权 2）+ 反向对照。

## 5. 工程约定与红线（接手必读）

- **Git**：分支 `main`（始终全绿）+ `feat/<主题>`；前缀 `feat:/fix:(写复现与根因)/rename:/refactor:/docs:/chore:`；合回 main 前 pytest 必须全绿。
- **入库红线**：`.env`、`data/pdfs/*.pdf`、`data/parsed/`、`data/index/`、`*.db`、`.workbuddy/`（含本机绝对路径与端点）一律不入库；push 后终检 `git ls-tree -r --name-only origin/main | grep -E "^\.env$|\.venv|\.workbuddy"`。
- **不承诺 100% 不幻觉**：只能降低概率、缩小影响面、加快定位。
- **所有外部调用**（LLM/检索/HTTP/DB）必须有显式超时 + 重试（次数+退避+抖动）+ 失败降级。
- **自主循环有界**：max_steps ≤ 12、token 预算、墙钟上限、停止条件、人工接管点。
- **凭据**：只从环境变量/密钥服务读，禁止硬编码与打日志；PII 脱敏。
- **语言**：与用户一致用中文（含代码注释与文档）；不写"校招项目/一周 MVP"。
- **代码完整性**：禁止 `...`/`TODO` 占位（TODO 只进"下一步"章节）；依赖写版本号。

## 7. 给新会话的提示（踩过的坑 / 认知）

1. **"是不是 Agent"** 是用户的执念，每次都要正面回答（见 §0），别只讲工程取舍。
2. **stale server 占端口**：起 uvicorn 前先 `lsof -ti tcp:8765 | xargs kill`；验证时保证 `lsof -ti tcp:8765` 的 PID == 你启动的 PID，否则测的是旧代码。
3. **FTS5 静默假阴性**：裸串 `match('资产总计')` → 0；必须 `match(" OR ".join(tokenize(q)))`（查询侧先 `apply_lexicon()` 注入财务词典）。
4. **单位识别用精确字典匹配**，不得后缀包含（`"万元".endswith("万")` 为假的教训）。
5. **容差由报表披露单位推导** = 科目数 × 0.5 × 单位，不得硬编码 0.01。
6. **评测必须主动读轨迹 `source` 统计降级率**，否则会重犯"看起来没效果、其实没被调用"的归因错误（P-015）。
7. **题库最大风险是标错不是漏题**：gold 标错会把系统正确行为判成错误（假阳性），所以必须有只读原始 PDF 的 G3 闸门。
8. **解析窗口是评测隐含前提**：本数据集只解析 p58–67，`out_of_parse_window` 类拒答题是人造的，报告里要写清。
9. **不要重复造轮子**：能 fork 的候选（kotaemon 的引用 UI）只抠组件，不整体 fork；RAGFlow 等已调研否决。
10. **留档判定**：技术方案有短板→换方法才进 `docs/技术问题留档.md`；缺库/配置/环境/手误（D/E/F/G/H）不进档。本轮新增 P-029（company/period 文档自动识别的认知修正）、P-030（财务口语简称静默命中子科目行，B 类静默）。
