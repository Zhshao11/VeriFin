# 真实财报问题示例（给「不懂财务的人」用）

> 这份文档不是「考系统会不会算」的题库，而是**真实世界里谁会问、为什么要问、系统该怎么答**的清单。
> 系统的定位是：你手里有一份年报（或一段被引用的数字），想确认这个数字在原文里到底存不存在、对不对得上内部勾稽关系。
> 凡标注「现在可演示」的，都能在 `web/` 演示页直接点出来；标注「需 Agent 计算路径」或「待补 F7」的，目前走编排层（`/api/agent`）或尚未接线，页面上不单列按钮。

---

## 一、手里有报告，要核对一个被引用的数字（最常见）

**真实人物**：读研报 / 看新闻的个人投资者、做尽调的分析师、写稿的财经记者。
**动机**：别人扔给你一个「茅台 2024 年营收 1709 亿」，你不想盲信，想点回原文确认。
**系统能力**：单点核验（`/api/ask`）—— 把数字逐字定位到原文页码并做 span 硬校验。

| 问题（你这样问就行） | 财务名词一句话 | 预期结果 | 状态 |
|---|---|---|---|
| 2024 年营业收入是多少 | 利润表第一行，公司一年卖东西收到的钱（未扣成本） | 170,899,152,276.34 元，定位 p63 | 现在可演示 |
| 2024 年归母净利润是多少 | 扣掉少数股东应占部分后，普通股股东真正享有的利润；别和「净利润」混 | 给出带页码的数字 | 现在可演示（标签：归属于母公司所有者的净利润） |
| 2024 年经营活动产生的现金流量净额是多少 | 主业「真金白银」进账，和净利润对照能看盈利质量 | 92,463,692,168.43 元，p67 | 现在可演示 |
| 2024 年资产总计是多少 | 公司家底总和（负债 + 权益） | 298,944,579,918.70 元，p59 | 现在可演示 |
| 资产负债率是多少 | 负债合计 ÷ 资产总计，衡量杠杆高低 | 目前只校验分子分母，**比率本身待补 F7** | 待补 F7（分子分母现在可演示） |

> 小知识：为什么特意区分「归母净利润」和「净利润」？因为子公司里有别人的股份（少数股东），「净利润」包含他们的份，「归母净利润」才是属于上市公司股东自己的。研报里说的通常是后者。

## 二、核对内部勾稽关系（发现数据矛盾的线索）

**真实人物**：审计、财务尽调、监管核查。
**动机**：报表内部的恒等式若不平，往往是录入错误或人为调节的信号。
**系统能力**：勾稽核验（`/api/identity` 已接 F1；F2/F3 走 `/api/agent`）。

| 问题 | 财务名词一句话 | 预期结果 | 状态 |
|---|---|---|---|
| 资产是不是等于负债加所有者权益 | 资产负债表第一恒等式，两边必须相等（容差由披露单位推导） | PASS，差额 0.00 | 现在可演示（05 区块按钮） |
| 净利润和留存收益变动对不对得上 | 利润表净利润应结转进权益（F2） | 恒等式核验 | 需 Agent 计算路径 |
| 经营、投资、筹资三类现金流加起来，是不是等于现金净增加额 | 现金流量表闭环（F3） | 恒等式核验 | 需 Agent 计算路径 |

> 小知识：「勾稽关系」是会计行话，意思就是「这几张表 / 这几行数字之间必须能对上」。对不上不一定是造假，也可能是录入错，但**值得追查**——这正是系统要帮你拦的第一道。

## 三、看趋势与盈利质量（同比 / 毛利率）

**真实人物**：长期跟踪一家公司的投资者。
**动机**：单看一年没意义，要跟去年比、看结构。
**系统能力**：Agent 计算路径（F4 毛利率、F6 同比变动、DIFF 两行相减）。

| 问题 | 财务名词一句话 | 预期结果 | 状态 |
|---|---|---|---|
| 今年营收比去年增长了多少 | 同比变动（F6），看增速是否放缓 | 给出变动额与比率 | 需 Agent 计算路径 |
| 毛利率有没有下滑 | （营收 − 营业成本）÷ 营收（F4）；持续下滑常预示价格战或成本失控 | 给出毛利率与同比 | 需 Agent 计算路径 |
| 经营现金流和净利润差多少 | 利润含金量；长期「净利差很多」可能是应收账款堆出来的纸面利润 | 两行相减（DIFF）或公式 | 需 Agent 计算路径 |

## 四、故意刁难：要它拒答 / 别编（护栏边界）

**真实人物**：评测者、安全审计、想挑刺的人。
**动机**：确认系统「不知道就说不知道」，而不是硬编一个数字。
**系统能力**：拒答（`NO_RECALL` / `wrong_document` 等）+ 防幻觉台（`/api/guard`）。

| 问题 | 为什么该拒答 | 预期结果 | 状态 |
|---|---|---|---|
| 火星基地折旧年限是多少 | 报告里根本没有，四路召回全 0 | 拒答 `NO_RECALL` | 现在可演示（红色芯片） |
| 五粮液 2024 年营收多少 | 问的是别的公司，主体约束应拦下 | 拒答 `wrong_document` | 现在可演示 |
| 把真实片段里的数字改一个零再喂回去 | 片段真、数字假，只读片段那层会放行 | 防幻觉台第二例必拦截 | 现在可演示（04 区块） |

## 五、财务名词速查（给零基础）

- **营业收入**：一年卖产品 / 服务挣的钱，还没扣成本和税。规模看它。
- **归母净利润 vs 净利润**：见上一节说明。看「公司股东赚了多少」用前者。
- **经营活动现金流量净额**：主业真实收到的现金减去真实花掉的现金。比净利润更难造假，是盈利质量的试金石。
- **资产 / 负债 / 所有者权益（股东权益）**：家底 = 欠别人的（负债）+ 真正属于股东的（权益）。三者恒等式是财报的基石。
- **毛利率**：（营收 − 营业成本）÷ 营收。反映产品本身赚不赚、定价权强不强。
- **资产负债率**：负债 ÷ 资产。越高杠杆越大、越脆；房地产业普遍高，白酒业普遍低。
- **同比（YoY）**：今年这期 vs 去年这期，排除季节因素看趋势。
- **勾稽关系**：报表内部必须自洽的数字勾连，对不上就要追查。

## 六、能力边界（诚实说明，不夸大）

1. **现在页面直接能点的**：单点核验（任意科目，带页码溯源）、F1 勾稽、防幻觉台、拒答演示、Agent 编排回放。
2. **走 `/api/agent` 计算路径能答、但页面未单列按钮的**：F2 / F3 勾稽、F4 毛利率、F6 同比、两行相减（DIFF）。
3. **待补的**：资产负债率等比率类（需新增 F7 公式）；上传任意 PDF 自动解析（封面结构化解析 + 全本解析窗口，目前演示用预解析的 p58–67 切片）；扫描版 PDF 的 OCR。
4. **不会做的（也是设计底线）**：绝不凭空编一个数字；六元组（公司 / 期间 / 指标 / 数值 / 单位 / 来源）缺一即程序级拒答，模型无否决权。

> 这套问题集刻意避开了「假大空」的考题，全部对应一个真实动作：*确认一个关于财报的数字是否站得住脚*。这才是本系统要解决的真实需求。
