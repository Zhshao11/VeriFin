VeriFin · 财报数字可溯源核验 Agent | 2026.06–2026.09 | 个人项目（开源，附在线 Demo）
技术栈：Python 3.13 · 自研编排框架（未用 LangChain/LangGraph）· MinerU 4.0.3 + PyMuPDF · jieba + 财务词典（131 术语 + 6 短语）· SQLite/FTS5 · glm-5.3（仅作路由层）
项目概述：输入 A 股年报并提问，系统把财务数字逐字定位回原文页码与行坐标，并做勾稽校验；证据不足即程序级拒答。解决"大模型给的财务数字查不着、错了定位不到"。
- 针对财务数字"答得出但查不着"，实现可溯源核验主链路：四路召回（科目名/词法/数值精确/向量，RRF k=60）→ 原文逐字校验 → PDF 同行坐标定位。33 题评测中数值与页码同时正确，页码不符 0 题。
- 针对"LLM 可路由但不能生成数值（否则校验形同虚设）"的取舍，自研 12 节点/8 工具显式编排图，LLM 仅在合法后继中选节点名，取值/算术/拒答全走确定性代码（max_steps=12 有界）。零 LLM 环境下 40 题全通（33 自建 + 7 对抗），7 条注入/越权全部未影响输出，反向对照假绿 0。
- 针对 jieba 默认词典把"营业收入"切成"营业+收入"、被"营业外收入"抢走排名（取错科目且不报错），注入 137 条财务词典并让纯数字查询改走 Decimal 精确匹配。固定 15 个报表科目、同一问句模板，对比词典开关两态的端到端检索 top-1 命中率：26.7%（4/15）→ 100%（15/15）。
- 针对自建评测"自说自话、解析错会带着标注一起错"，设计三道独立闸门（索引页/证据同页可定位/只读原始 PDF 文本层），判分对齐 FinanceBench、FinQA 的精确匹配（Exact Match）口径。该轮 29 题自建集**一轮逼出 7 个单测未发现的缺陷**，补护栏后 72.4%（21/29）→ 100%（29/29），母公司口径 0/2 → 2/2、误答清零。
- 针对"口语简称答非所问"（问"经营现金流"命中子科目行，数值真、页码真、span 过关，非财务专家分不出对错），定位到两层缺陷：检索入口无简称归一 + 演示入口 `/_api/ask` 自己重写验证路径、从未调用问答一致性护栏。修法：简称归一收敛到检索入口（四入口共用）+ 统一歧义判定 + 演示入口补护栏；题库扩至 33 题守住该缺陷，反向对照证明新题非假绿。
